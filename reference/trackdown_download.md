# trackdown_download

This function automates a trackdown download from google drive based on
the script of `download_trackdown.R`

## Usage

``` r
trackdown_download(dl_filePattern = "download_trackdown.R", force = FALSE, ...)
```

## Arguments

- dl_filePattern:

  the file pattern for the script used to automate the download

- force:

  logical. should the script force the download if multiple scripts are
  located

- ...:

  additional arguments passed to function

## Value

nothing
