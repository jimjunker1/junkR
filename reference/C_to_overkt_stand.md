# C_to_overkt_stand

This functions converts to celcius to inverse Boltzmann temperature
(1/kT) from a set standard, e.g., 15 C

## Usage

``` r
C_to_overkt_stand(a = NULL, mu = 15)
```

## Arguments

- a:

  This is the temperature in celcius

- mu:

  This is the standardization temperature in celcius
