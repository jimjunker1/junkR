# trackdown_upload

This function automates a trackdown upload to google drive based on the
script of `upload_trackdown.R`

## Usage

``` r
trackdown_upload(ul_filePattern = "upload_trackdown.R", force = FALSE, ...)
```

## Arguments

- ul_filePattern:

  the file pattern for the script used to automate the upload

- force:

  logical. should the function continue if multiple scripts are
  identified

- ...:

  additional argument passed to function

## Value

nothing
